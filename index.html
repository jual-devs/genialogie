Génialogie

Un arbre généalogique à construire à plusieurs, enregistré dans un dépôt GitHub privé.

Vos arbres sur cet appareil

    Rejoindre un arbre

    Quelqu'un du groupe vous a transmis un code ou un lien ? Ouvrez l'arbre avec. Aucun compte GitHub n'est nécessaire.

    Créer un arbre

    Vous démarrez un nouvel arbre. Il sera enregistré dans un dépôt privé de votre compte GitHub, et vous inviterez le groupe avec un code.

    Aucun serveur de Génialogie ne reçoit vos données : cette page parle directement à GitHub depuis votre navigateur. Le code que vous saisissez reste sur cet appareil.

    Rejoindre un arbre

    Collez le code de groupe, ou ouvrez le lien d'invitation qu'on vous a envoyé.

    Créer un arbre

    Il vous faut un compte GitHub. Trois étapes, environ cinq minutes.

    1. Créer le dépôt privé

      GitHub s'ouvre dans un nouvel onglet avec le formulaire déjà rempli. Gardez « Private », cochez « Add a README file », puis cliquez sur « Create repository ».

      Ouvrir GitHub

    2. Créer un jeton d'accès

      Sur la page du jeton, dans « Repository access », choisissez « Only select repositories » puis ce dépôt. Cliquez sur « Generate token » et copiez le jeton (il commence par github_pat_).

      Ouvrir la création du jeton

    3. Coller le jeton

    Le jeton donne accès à ce seul dépôt. Il est gardé sur cet appareil et sert à fabriquer le code de groupe.
