# genialogie
Génialogie : Arbre généalogique collaboratif avec des fiches de personnes liées (parent/enfant, mari/femme) et un arbre explorable à souhait.  L'outil fonctionne à 100% dans le navigateur (Hébergé sur GitHub Pages); les données restent dans un dépôt privé (arbre.json), partagé par un simple code de groupe. Sans serveur ni compte pour les invités.
