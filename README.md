## Génialogie
Application web pour créer et visualiser un arbre généalogique à plusieurs, sans serveur.

Fiches : prénom, nom, profession, naissance, mariage, décès, liens époux/parents/enfants
Arbre zoomable et déplaçable, centré sur une personne (ancêtres et descendants réglables)
Collaboration : les données sont dans arbre.json d'un dépôt GitHub privé ; les modifications simultanées sont fusionnées
Partage : un code de groupe suffit pour rejoindre un arbre (sans compte GitHub), avec option lecture seule
Multi-arbres, thème clair/sombre, utilisable sur mobile
JavaScript natif, aucune dépendance, déployable sur GitHub Pages

⚠️ Le code de groupe contient un jeton d'accès : à traiter comme un mot de passe.
